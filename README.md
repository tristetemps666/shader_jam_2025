# A table !
![ezgif-206f61ef265f10b1](https://github.com/user-attachments/assets/a7dae44f-854e-43e9-9b6b-b3604d5d9564)

Rendu du projet Unity.
Vous trouverez aussi dans Build.rar la build jouable du projet, et ici présent un README détaillant le fonctionnement du jeu.


Pitch
-
A table raconte l'histoire d'un requin léopard affamé qui mange plein de poissons.
Vous contrôlez un requin léopard avec la souris et pouvez dévorer les poissons dans la lagoon. 

Liste des choses réalisés en lien avec le cours
- 
- Shader
- VFX (Particules)
- Déplacement d'un character
- Physique
- Etats de jeu (état de pause, état de jeu)
- Collecte d'objets
- Animation
- IA et pathfinding
- Menu titre, menu pause
  Todo :
  - SFX
  - UI overlay
  - Etat de fin de jeu


Schémas de contrôle
-
- Souris : déplacement du requin léopard
- Echap : menu pause
- Clic : interactions avec les boutons du menu pause
